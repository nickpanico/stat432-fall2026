If two KNN models using different distance metrics have test error rates of 12.5% and 13.5% on a single test set, is that enough evidence to conclude that the model with the 12.5% test error has better prediction performance? If not, what is a good check to determine whether the difference indicates a real difference in prediction performance or is simply due to random variation in the data?
